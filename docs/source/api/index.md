# Referência da API

Todas as funções abaixo também podem ser usadas direto do pacote: `qbasic.ket` é o mesmo que `qbasic.estados.ket`.

| Módulo | Conteúdo |
|---|---|
| {doc}`qbasic.objeto <objeto>` | A classe {class}`~qbasic.objeto.ObjQuantico`, base de estados e operadores (densos ou esparsos). |
| {doc}`qbasic.estados <estados>` | Vetores da base, kets de qubits, Fock, coerente, Bell, GHZ, W e matriz densidade. |
| {doc}`qbasic.operadores <operadores>` | Identidade, criação/destruição, número, posição/momento, Pauli, produto tensorial e comutadores. |
| {doc}`qbasic.portas <portas>` | Portas de um e de vários qubits para circuitos. |
| {doc}`qbasic.medidas <medidas>` | Valores esperados, probabilidades, amostragem, traço parcial, pureza, entropia, fidelidade e vetor de Bloch. |
| {doc}`qbasic.dinamica <dinamica>` | Equações de Schrödinger e de Lindblad. |
| {doc}`qbasic.visualizacao <visualizacao>` | LaTeX, função de Wigner e gráficos. |
