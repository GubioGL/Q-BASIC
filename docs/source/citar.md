# Como citar

Se o Q-BASIC ajudou no seu trabalho, cite o software. No GitHub, o botão
**"Cite this repository"** (gerado a partir do arquivo `CITATION.cff`) fornece a referência
em APA e BibTeX.

```bibtex
@software{qbasic,
  author  = {Gomes de Lima, Gubio},
  title   = {{Q-BASIC}: Quantum Brazilian Algorithms, SImulations, and Computational tools},
  year    = {2026},
  version = {0.1.0},
  url     = {https://github.com/GubioGL/Q-BASIC}
}
```
