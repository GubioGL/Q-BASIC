Este livro reúne os tutoriais do **Q-BASIC** (*Quantum Brazilian Algorithms, SImulations,
and Computational tools*), uma biblioteca de simulação quântica em Python feita para o
ensino e a pesquisa. Ele é gerado automaticamente a partir dos notebooks Jupyter da pasta
`tutoriais/` do repositório, então o texto, os códigos e os resultados são exatamente os
dos notebooks.

A **Parte I** constrói, passo a passo, um simulador quântico: estados e operadores como
matrizes, as operações entre eles, o estado coerente, a matriz densidade, Hamiltonianos de
sistemas acoplados, a solução da equação de Schrödinger e as matrizes esparsas. As últimas
aulas usam a biblioteca pronta para estudar a função de Wigner, o emaranhamento e
sistemas abertos. A **Parte II** trata de computação quântica: qubits, portas lógicas,
medidas, emaranhamento e teleportação.

Para reproduzir os exemplos, instale a biblioteca e as dependências dos tutoriais com
`pip install "Q-BASIC[tutorial]"` e abra os notebooks no Jupyter. Os blocos de código
aparecem como no notebook, seguidos das saídas (com uma barra cinza à esquerda). Algumas
células mostram um **erro de propósito**, destacado em vermelho: a aula seguinte mostra
como resolvê-lo.

O Q-BASIC é software livre (licença MIT). Correções e sugestões são bem-vindas no
repositório <https://github.com/GubioGL/Q-BASIC>.
